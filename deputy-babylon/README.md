# Депутат: 7 дней до выборов — web-порт на Babylon.js

Порт «1 в 1» Godot-версии проекта (`../`): вся логика перенесена, рендер мира —
Canvas2D в `BABYLON.DynamicTexture` (top-down пиксель-арт), интерфейс — DOM-оверлей.

## Запуск

```bash
cd deputy-babylon
node serve.js 8137        # или: npx http-server -p 8137
# открыть http://localhost:8137
```

Тесты логики (порт tests/smoke_test.gd, 43 проверки):

```bash
node tests/smoke.js       # или: npm test
```

Babylon.js лежит локально (`assets/vendor/babylon.js`, UMD с jsDelivr) — интернет не нужен.

## Управление

- WASD / стрелки — идти (на сенсорных экранах — левый джойстик)
- E / Space — взаимодействие (можно кликать подсказку внизу)
- Q / Tab — телефон, Esc — меню

## Редактор карты

Открыть: клавиша **F2** или `http://localhost:8137/?edit=1`.

- Клик — выбрать объект, тянуть мышью — двигать. В списке справа — все объекты и координаты.
- Стрелки — сдвиг выбранного на 1px (Shift — 10px), WASD — панорама камеры.
- Над каждым объектом на карте подпись: что это (дом, дерево, дорога, точка NPC…).
- **💾 Сохранить в файл** — пишет `data/city_layout.json` (работает при запуске через `node serve.js`).
- **⬇ Скачать JSON** — если сервер статический (без POST), файл скачается; положить в `data/`.
- **↺ Сброс** — вернуть раскладку из `data/city.json`.

При старте игра читает `data/city_layout.json`, если он есть: это отдельный файл, `city.json` не
изменяется. Раскладка включает: здания (с дверями), дома, деревья, скамьи, фонари (ряды), машины,
пропсы, почтовые ящики, автобусные остановки, точки NPC, площадь, парк, район, дороги, зебру.
